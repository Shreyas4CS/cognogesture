How it works

The same path real AI engineers follow: collect data, train models, test them fairly, then deploy the best one.

Collect data

Add gestures (hand signs, faces or objects), hold Record for 50–150 pictures each, and set the robot's default PWM speed.

Train 4 models

KNN, a Neural Network, an SVM and a Random Forest all learn from the same pictures.

Test & choose

Each model is tested on pictures it never saw. Compare the accuracy and pick the winner.

Drive live

Connect the robot and steer through the maze, with a live speedometer. Unknown signs stop it.
